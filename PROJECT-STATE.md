## 1. Резюме решения

Разработан интернет-магазин «Новый Минерал» на Next.js 16 (App Router) + TypeScript +
Tailwind CSS v4. Реализованы главная, каталог с серверными фильтрами, страница
экземпляра, поиск, избранное, корзина, промокоды, оформление заказа, личный кабинет
и слой интеграций (доставка, оплата, письма) за интерфейсами.

Продакшен-сборка проходит: **83 страницы**, 0 ошибок TypeScript, 0 ошибок ESLint.

### Отклонения от протокола (зафиксированы осознанно)

**Интервью не проводилось.** `cloud.md` требует структурированного интервью до
проектирования. Заказчик передал детальное ТЗ (`noviy_mineral.md`, 73 раздела) и
команду начинать. ТЗ принято как результат этапов Interview → UI System.
Ретроспективно не хватает: реального ассортимента, контактов, юридических данных,
правил доставки — они перечислены в разделе 9 как запрос заказчику.

**Рекомендация ui-ux-pro-max отклонена.** Скилл предложил стиль «Vibrant &
Block-based» с зелёно-оранжевой палитрой. Это противоречит ТЗ (фирменный
бирюзовый заказчика, п.50) и прямому запрету generic-блочного e-commerce (п.6).
Из скилла взят только pre-delivery чек-лист (контраст, focus-состояния,
SVG вместо эмодзи, reduced-motion, тач-цели 44 px).

## 2. Дизайн-система

Токены заданы CSS-переменными в `src/app/globals.css`. HEX-значений в компонентах нет.

### Цвет

Фирменные цвета сняты **пиксельным анализом оригинальной аватарки VK**, а не подобраны
на глаз (требование п.50 ТЗ).

| Токен | Значение | Роль |
|---|---|---|
| `--brand` | `#0C676A` | фон логотипа (82.4 % площади аватарки); CTA, ссылки, активные состояния |
| `--brand-hover` / `--brand-active` | `#095356` / `#073F42` | состояния кнопок |
| `--brand-soft` | `#E6F2F2` | подложки акцентов, чипсы фильтров |
| `--brand-bright` | `#2AB8C6` | заливка кристалла в логотипе; декоративный акцент |
| `--background` / `--surface` | `#FFFFFF` / `#F5F8F8` | фон страницы / чередующиеся секции |
| `--foreground` / `--muted-foreground` | `#101A1B` / `#5A6A6B` | текст / вторичный текст |
| `--border` / `--border-strong` | `#E2E8E8` / `#CDD6D6` | разделители / рамки полей |
| `--success` / `--warning` / `--danger` | `#10704A` / `#9A5B00` / `#B3261E` | статусы |

Контраст `#0C676A` на белом ≈ 6:1 — проходит AA для текста и для белого текста на кнопке.
`#2AB8C6` используется только как графический акцент, не для текста.

### Типографика

Одна гарнитура — **Onest** (400/500/600/700), подключена через `next/font/google`
с кириллическим сабсетом. Выбрана за спокойный характер, читаемость и ровные цифры.
Цены и артикулы выводятся классом `.tnum` (табличные цифры), чтобы столбцы не «плясали».

### Геометрия и движение

Радиусы 4 / 6 / 10 / 14 px — умеренные, без «огромного border-radius» из п.6 ТЗ.
Тени только у всплывающих слоёв. Длительности 150 / 200 / 250 ms, easing
`cubic-bezier(.22,.61,.36,1)`, `prefers-reduced-motion` уважается.

### Сетка

Контейнер `max-width: 1440px`, паддинги 16 / 32 / 48 px по брейкпоинтам.
Каталог на 1440 px: сайдбар 264 px + **3 карточки** в товарной области — фотография
остаётся крупной. На мобильных 2 карточки в ряд.

## 5. Логика интерфейса

**Состояние каталога только в URL.** Фильтры, сортировка и страница не имеют другого
хранилища, поэтому Back/Forward и обновление работают без отдельного кода.

**Фасеты считаются по категории и поисковому запросу, но без учёта самих фильтров** —
иначе, выбрав «аметист», пользователь потерял бы возможность добавить второй минерал.

**Уникальный экземпляр:** `uniquePiece = true` → `stock` принудительно 1, выбор
количества скрыт, в корзине «1 экземпляр», сервер при оформлении обрезает количество до 1.

**Промокод живёт в общем состоянии** (`StoreProvider`), хранится только код —
сумма скидки пересчитывается от актуальной корзины. Поэтому код переносится из
корзины в оформление и не «залипает» с устаревшей суммой. Сервер проверяет код заново.

**Гость и аккаунт.** Без авторизации корзина и избранное в localStorage. При входе
данные **сливаются** с аккаунтом, а не затираются. Покупка без регистрации возможна,
регистрация между корзиной и оплатой не встаёт.

**Честные статусы.** Если платёж не подтверждён, страница успеха пишет
«Ожидает оплаты», а не «оплата прошла успешно».

## 7. Данные и ассеты

**Логотип настоящий.** Получен со страницы VK через OpenGraph-разметку (прямой доступ
к странице заблокирован). Аватарка 1998×1998 → знак вырезан из оригинала,
не перерисовывался. Все обращения — через `src/config/brand.ts`.

**Demo-каталог:** 44 товара, 19 минеральных видов, 15 месторождений, 15 категорий,
12 цветов, 5 признаков экземпляра. Разные типы товаров, карточки не клонированы.

**Фотографии:** 43 файла — 39 из Wikimedia Commons со свободными лицензиями
(CC0 / CC BY / CC BY-SA / PD) и 4 фирменные заглушки там, где подходящего
свободного снимка не нашлось (книги, оптика, бокс, второй шар).
Атрибуция — `public/demo/attribution.json` и страница `/about`; заглушки в неё
не входят, чтобы не приписывать авторство чужим людям.

## 9. Требуется от заказчика

Без этого сайт нельзя запускать как настоящий магазин:

1. **Выгрузка каталога** — товары, артикулы, цены, остатки, размеры, вес, месторождения.
2. **Фотографии товаров** — каждый коллекционный экземпляр снят индивидуально.
3. **Контакты** — телефон, email, адрес, часы работы.
4. **Юридические данные** — наименование, ИНН, ОГРН (обязательны для интернет-торговли).
5. **Правила доставки, оплаты и возврата** — реальные сроки и условия.
6. **Подтверждение обещаний с обложки VK** — бесплатная доставка от 5000 ₽, подарки.
7. **Credentials** — СДЭК, CDEK PAY, сервис рассылки.
8. **Реальные промокоды**, если они нужны на старте.
