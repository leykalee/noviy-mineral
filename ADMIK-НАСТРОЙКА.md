# Новый Минерал × Admik — настройка магазина

Витрина «Новый Минерал» работает как **потребитель** админки Admik: каталог,
цены, наличие, заказы и доставка живут в Admik, витрина их только показывает.

## Доступы

- **Админка:** http://130.49.143.37:8080/admin
- **Витрина:** http://130.49.143.37
- Логин/пароль владельца — в `/root/ADMIK-CREDENTIALS.txt` на сервере
  (смените пароль в админке → «Аккаунт»).

## 1. Категории

Витрина берёт дерево категорий из Admik автоматически (меню «Каталог», плитки,
хлебные крошки). Кураторское меню в шапке ссылается на такие **slug** категорий —
заведите их в админке с этими же slug, чтобы ссылки вели на непустые разделы:

```
minerals, boxes, rarities, fossils        (Минералы)
crafts, decor, models, polished           (Изделия)
jewelry, beads, bracelets                 (Украшения)
books, accessories, tumbled               (Прочее)
```

Можно завести не все — лишние пункты меню просто приведут в пустой раздел.
Дерево (родитель→дети) поддерживается: например `minerals` → `boxes`.

## 2. Товары и характеристики (важно)

Специфика минералов задаётся в товаре **атрибутами** (ключ → значение). Витрина
читает их регистронезависимо, ключи можно писать по-русски или латиницей:

| Что показывается на карточке | Ключ атрибута (любой из) |
|---|---|
| Минерал (вид) | `минерал` / `mineral` |
| Месторождение | `месторождение` / `deposit` |
| Страна | `страна` / `country` |
| Регион | `регион` / `region` |
| Ширина, мм | `ширина` / `width` |
| Высота, мм | `высота` / `height` |
| Глубина/толщина, мм | `глубина` / `depth` |
| Вес, г | `вес` / `weight` |
| Цвет(а) | `цвет` / `color` (можно через запятую) |
| Материал | `материал` / `material` |
| Особенности | `особенности` / `features` (УФ, фантом, включения, габитус, двойники) |
| Уникальный экземпляр | `уникальный` / `unique` = да/нет |
| Краткое описание | `краткое` / `shortDescription` |

Всё необязательно: чего нет — просто не показывается. Габариты и вес заполняются
числами. Цена/старая цена, фото, наличие, флаги «новинка/рекомендуемый/скидка» —
стандартные поля товара Admik.

## 3. Что уже работает и что позже

- **Работает:** каталог по категориям и поиску, карточка товара со всеми
  характеристиками, новинки/рекомендуемые/скидки, оформление заказа и расчёт
  СДЭК через Admik, форма вопроса.
- **Этап 2:** фасетные фильтры в сайдбаре (по минералу/месторождению/цвету/
  размеру) и отдельная навигация «по минералам/месторождениям» — их пока нет в
  Storefront API Admik (нужна доработка бэкенда). Сейчас фильтрация идёт по
  категории, поиску и флагам.

## 4. Боевые ключи (когда появятся)

СДЭК и онлайн-оплата (Т-Банк) сейчас в demo-режиме. Боевые ключи задаются в
`/opt/admik/.env` (`CDEK_*`, `TBANK_*`), затем `docker compose up -d app` на сервере.
