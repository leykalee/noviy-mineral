# Новый Минерал

Интернет-магазин коллекционных минералов и изделий из натурального камня.
Прототип фронтенда, готовый к подключению боевого каталога и интеграций.

Бренд, логотип и фирменные цвета — настоящие, взяты со страницы магазина
[vk.ru/noviy_mineral](https://vk.ru/noviy_mineral). Товары, цены и фотографии —
демонстрационные, см. раздел «Что здесь ненастоящее».

---

## Как запустить

```bash
npm install
cp .env.example .env.local   # необязательно: без него работают demo-провайдеры
npm run dev                  # http://localhost:3000
```

Продакшен-сборка:

```bash
npm run build
npm start
```

Проверки:

```bash
npm run typecheck   # tsc --noEmit
npm run lint        # eslint
npm run build       # production build
```

Требуется Node.js 20.9+ (проект собирается и проверяется на 22).

## Стек

| Слой | Выбор | Почему |
|---|---|---|
| Фреймворк | Next.js 16, App Router | серверная фильтрация каталога и SEO из коробки |
| Язык | TypeScript, strict | предметная модель описана типами |
| Стили | Tailwind CSS v4 | токены заданы в CSS-переменных, без HEX в компонентах |
| Валидация | Zod | одна схема на клиент и сервер |

| Шрифт | Onest | современный гротеск с качественной кириллицей, одна гарнитура |

## Ключевые архитектурные решения

**Экземпляр, а не SKU.** Коллекционный образец — конкретный физический предмет:
свой артикул, размеры, вес и статус `available | reserved | sold_out`.
При `uniquePiece = true` склад принудительно равен 1, выбор количества не
показывается, купить два невозможно. Проданный экземпляр остаётся доступным по URL
и предлагает похожие.

**Три независимые оси навигации.** Категория (тип товара), минеральный вид и
месторождение — разные сущности, а не ветки одного дерева. Поэтому по ним можно
фильтровать независимо, а `/minerals/[slug]` и `/deposits/[slug]` добавляются
без переделки модели.

**Состояние каталога живёт только в URL.** Другого хранилища у фильтров нет,
поэтому «Назад», «Вперёд» и обновление страницы работают сами собой, а
`?page=2` открывается напрямую. Разбор и сборка — `src/lib/catalog-query.ts`.

**Фильтрация на сервере.** Каталог рассчитан на 2000+ SKU: выборка, фасеты со
счётчиками и пагинация считаются в `src/lib/repository.ts`, в браузер уезжает
одна страница выдачи.

**Замена источника данных — одно место.** Весь код обращается к
`src/lib/repository.ts`. Чтобы перейти с demo-массива на PostgreSQL или на внешний
Storefront API, меняются только тела его функций; сигнатуры остаются прежними.

**Интеграции за интерфейсами.** `DeliveryProvider`, `PaymentProvider` и
`EmailProvider` — отдельные контракты. Есть боевые credentials — работает боевой
провайдер, нет — демонстрационный, и он честно сообщает об этом через `isLive: false`.
Ключи читаются только на сервере.

## Что здесь ненастоящее

Прототип нигде не выдаёт выдуманные данные за реальные (это требование ТЗ).

| Что | Состояние |
|---|---|
| Логотип, фирменные цвета, слоган | **настоящие**, со страницы VK |
| Товары, цены, артикулы, месторождения, остатки | демонстрационные, `src/data/demo/products.ts` |
| Фотографии товаров | свободные лицензии Wikimedia Commons, атрибуция в `public/demo/attribution.json`; часть — фирменные заглушки |
| Телефон, email, адрес, юрлицо, ИНН | **не переданы** — в `storeConfig` стоит `null`, UI такие блоки не рисует |
| Сроки, тарифы, условия возврата | не переданы; `/delivery` описывает механизм, а не выдуманные цифры |
| «Бесплатная доставка от 5000 ₽», «подарки» | взяты с обложки VK, но **выключены** до подтверждения заказчиком |
| Промокоды | демонстрационные (`МИНЕРАЛ10`, `КОЛЛЕКЦИЯ500`, `ВЕСНА`, `АРХИВ`) |
| Оплата | не проводится: заказ остаётся в статусе «ожидает оплаты» |
| Накладные СДЭК | не создаются, тарифы условные |
| Письма | пишутся в лог сервера с пометкой «НЕ отправлено» |
| Авторизация | без серверной проверки пароля, сессия в браузере |
| Заказы | хранятся в памяти сервера и в localStorage браузера |

Чтобы заменить логотип — положите файлы по путям из `src/config/brand.ts`.
Если логотипа нет, поставьте `isRealLogo: false`, и появится текстовый fallback.

## Переменные окружения

Полный список с пояснениями — в `.env.example`. Коротко:

| Переменная | Без неё |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | canonical и sitemap ссылаются на localhost |
| `DATABASE_URL` | работает demo-каталог из `src/data/demo` |
| `CDEK_ACCOUNT`, `CDEK_SECURE_PASSWORD` | доставка считается демонстрационным провайдером |
| `CDEK_PAY_MERCHANT_ID`, `CDEK_PAY_SECRET_KEY` | платежи не проводятся |
| `EMAIL_API_ENDPOINT`, `EMAIL_API_KEY`, `EMAIL_FROM` | письма только в лог |
