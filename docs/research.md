## 1. Заказчик (VK)

Источник: https://vk.ru/noviy_mineral → `vk.ru/public215855991` (ID сообщества **215855991**).

Прямой доступ к странице заблокирован (VK отдаёт SPA-оболочку или заглушку
«устаревший браузер»). Данные получены из OpenGraph-разметки, которую VK отдаёт
краулерам социальных сетей.

### Что получено достоверно

| Поле | Значение |
|---|---|
| Название | **Новый минерал** |
| Слоган (статус) | «Новые минералы для души и коллекции!» |
| Позиционирование | «помощь любителям камня в подборе и оформлении коллекций, а также в исследовании удивительного мира неживой природы» |
| Подписчиков | 2 756 (на момент сбора) |
| Записей | 847 |
| Аватар | получен, 1998×1998 → `/public/brand/` |
| Обложка | получена, 1920×768 → `/public/brand/vk-cover.jpg` |

### С обложки сообщества (текст самого заказчика)

- «коллекционные минералы и изделия из камня» — фактически готовый дескриптор бренда;
- «Широкий ассортимент»;
- «Бесплатная доставка от 5000 рублей»;
- «Подарки к каждому заказу».

> ⚠️ Три последних пункта — маркетинговые обещания с обложки VK. Они **вынесены в
> `src/config/store.ts` как выключенные по умолчанию** и требуют подтверждения
> заказчиком перед показом на сайте (п.61 ТЗ: не выдумывать условия доставки).

### Чего получить не удалось

- телефон, email, адрес, юрлицо, ИНН;
- реальный товарный каталог и остатки;
- фотографии товаров.

Всё перечисленное → `storeConfig` с `null` и корректным скрытием в UI.

## 2. Логотип и фирменные цвета

Логотип **реальный**, взят с аватарки сообщества, не перерисовывался.

Композиция: знак (вытянутый кристалл + шеврон-«галка» под ним, белая обводка) +
шрифтовая часть «НОВЫЙ МИНЕРАЛ» в две строки с горизонтальными линейками,
всё на плотном тёмно-бирюзовом поле.

### Точные цвета (пиксельный анализ аватарки 1440×1440)

| Цвет | HEX | Доля площади | Роль в логотипе |
|---|---|---|---|
| Тёмный teal | **`#0C676A`** | 82.4 % | фон-поле логотипа |
| Бирюзовый | **`#2AB8C6`** | 1.6 % | заливка кристалла и шеврона |
| Белый | `#FFFFFF` | 3.3 % | обводка знака, текст, линейки |

Это и есть «фирменный бирюзовый» из брифа — оттенок не подбирался на глаз.
`#0C676A` работает как тёмная брендовая база, `#2AB8C6` — как яркий акцент.

### Подготовленные файлы

| Файл | Что это |
|---|---|
| `brand/logo-avatar.png` / `.jpg` | полная аватарка без изменений (OG, соцсети) |
| `brand/logo-mark.png` | знак, вырезан из оригинала, фон переведён в прозрачность |
| `brand/logo-mark-badge.png` | знак на фирменной плашке `#0C676A` — для хедера |
| `brand/icon-64.png` | favicon |
| `brand/vk-cover.jpg` | обложка сообщества |

Все обращения к логотипу идут через один компонент `components/brand/Logo.tsx` —
заменить ассет можно в одном месте.

## 3. Конкуренты

### 3.1 kamnevedy.ru

**Меню:** О нас · Доставка и оплата · Программа лояльности · Клуб · Контакты
**Входы в каталог:** Новинки · Камни А–Я · По знаку Зодиака · По месторождениям · Премиум подарки · РАСПРОДАЖА
**Ассортимент:** украшения (браслеты, серьги, колье, бусы), камни и минералы, метеориты,
окаменелости, бусины, кабошоны и огранка, книги, сувениры, предметы интерьера.
**Карточка:** название + происхождение («Бразилия, Minas Gerais») + цена + в корзину, бейдж «new».
**Цены:** 540 ₽ … 280 000 ₽.

**Вывод:** каталог имеет **несколько параллельных входов**, а не одно дерево категорий.
Берём: вход по минералу (А–Я), вход по месторождению, новинки, распродажа, подборки-подарки.
**Не берём:** навигацию по знакам Зодиака — это эзотерика, ТЗ прямо её запрещает (п.15, п.11.2).

### 3.2 rusmineral.ru

**Меню:** Главная · Новости · Каталог · Магазин · Выставки · Доставка · Контакты
**Категории:** Минералы · Изделия · Метеориты · Окаменелости · Минералогический антиквариат ·
Коллекции минералов · Литература · Сопутствующие товары · Новинки
**Карточка:** название + **артикул** (`Арт.XXXXX`) + цена + «Добавить в корзину».

**Вывод:** ключевая предметная модель — **артикул на конкретный физический экземпляр**,
цена относится к этому экземпляру. Это основа нашей модели `uniquePiece` + `sku` + `status`.
Разделы «Литература» и «Сопутствующие товары» подтверждают состав каталога из брифа.

### 3.3 leonmin.ru

**Разделы:** Коллекционные минералы · Агаты · Полированные камни · Шары и яйца ·
Метеориты, тектиты · Изделия, коллекции · Искусственные кристаллы · Окаменелости ·
Боксы, подставки, мастики · Для ювелиров
**Внутри «Коллекционных минералов»** — 300+ минеральных видов + поперечные срезы:
Включения (21) · Габитус необычный (115) · **УФ свечение (132)** · Фантомы, зональность (16)
**Фильтры:** диаметр (мм), высота (мм), наличие; сортировка по дате и цене.
**География:** Алтай, Урал, Сибирь, Карелия, Кавказ + зарубежные образцы.

**Выводы:**
1. Классификация двухслойная: **тип товара** × **минеральный вид** — их нельзя смешивать
   в одно дерево. У нас: `category` (тип) и `mineral` (вид) — разные сущности, как в п.47 ТЗ.
2. Счётчики товаров у каждой ветки — обязательны, каталог большой.
3. **Срезы-признаки** («УФ свечение», «фантомы», «необычный габитус») — сильная идея
   для коллекционера. У нас это `features[]` у товара + фильтр, а не отдельные категории.
4. Фильтр по физическим размерам в мм — рабочий; у нас размер + вес.

## 4. Что НЕ берём

- визуальный язык всех трёх (плотные текстовые меню, мелкая типографика, интерфейс 2010-х);
- сетки по 5–6 мелких карточек в ряд;
- навигацию по знакам Зодиака и любые «магические свойства» камней;
- фотографии товаров конкурентов — использовать запрещено (п.49 ТЗ).

## 5. Продуктовые решения, принятые по итогам research

1. **Два входа в каталог под две аудитории.**
   Новичок → визуальные категории + подборки по сценарию («в подарок», «до 3 000 ₽»).
   Коллекционер → минерал / месторождение / глубокие фильтры / артикул в поиске.

2. **Экземпляр, а не SKU.** Товар с `uniquePiece = true` имеет `stock = 1`, свои
   размеры и вес, статус `available | reserved | sold_out`. Проданный экземпляр
   остаётся доступным по URL (SEO + доверие) и предлагает похожие.

3. **Категория ≠ минерал ≠ месторождение.** Три независимые оси навигации.
   `/catalog/[category]` — сейчас; `/minerals/[slug]` и `/deposits/[slug]` —
   архитектурно заложены (п.8 ТЗ), данные и связи уже есть в модели.

4. **Цвет даёт минерал, не интерфейс.** Бирюзовый — только акцент: CTA, ссылки,
   активные состояния, служебные плашки. Фон — светлый нейтральный.

5. **Фильтры — серверные.** При 2000+ SKU фильтрация и пагинация на сервере,
   состояние в URL, `?page=N` работает напрямую.
